# M3：物业报修工单

负责上报、派单、维修中、超时升级、完工验收和评价。某自习室有维修中工单时，经 M1 公开网络 API 下架全室座位；验收通过撤销该工单限制，其他工单与占用继续生效。

派单规则、超时阈值、验收角色、工单取消、评价隐私、既有预约处置及写回重试/补偿待细化。禁止直接访问 M1 数据表。当前仅实现 `main.py` 的 FastAPI 应用及 `GET /health`，无业务功能。`tests/test_health.py` 验证 200/405/404 行为。命令见[根 README](../../../README.md#本地开发与基础验证)，约定见 [health](../../../contracts/health.md)。
