# M1：自习座位预约

负责搜索（含插座条件）、整点小时预约、签到、提醒触发、违约、历史复用、运营查询及有效可用状态。默认单次上限 4 小时可配置；开始前 15 分钟提醒，开始后 10 分钟未签到再提醒，15 分钟未签到取消、释放、提醒并记违约。每日动态签到编码与教室关联，Web 录入签到。

D 管理 RBAC 与空间/座位主数据，M1 通过公开 API 使用。M1 接收 M2 时段占用和 M3 维修限制，记录来源模块、来源业务记录、目标/时段和关联信息；撤销只对应一个来源，再计算可用性。

多个工单、既有预约遇维修、审批与个人预约冲突、取消/过期政策和签到安全细则待确认。此目录无实现，单元测试后续随代码加入。
