# M2：整教室预约与审批

负责权限门槛、申请、多级通过/驳回、超时自动撤销及状态查询。权限依据 D 公开接口；通过后经 M1 公开网络 API 占用全室指定时段，驳回/超时撤销时撤销该申请占用，保留其他来源限制。

审批级数/角色、超时阈值、取消政策、审批与占用成功的关系、个人预约冲突及失败补偿待细化验收。禁止直接修改 M1 数据表。当前仅实现 `main.py` 的 FastAPI 应用及 `GET /health`，无业务功能。`tests/test_health.py` 验证 200/405/404 行为。命令见[根 README](../../../README.md#本地开发与基础验证)，约定见 [health](../../../contracts/health.md)。
