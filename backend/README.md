# 后端组织

后端使用 Python 3.12 + FastAPI，依赖由根目录 uv 配置与锁文件统一管理。M1/M2/M3 各有最小 `main:app` 入口及 `/health`，D 尚无实现。初始化、启动、测试命令见[根 README](../README.md#本地开发与基础验证)。`modules/m1`、`m2`、`m3`、`d` 是领域边界，不表示已经确定独立服务部署。

后续各模块按实际规模组织公开 API、应用服务、领域规则、数据访问及单元测试，不预先堆叠分层空文件。启动装配与技术配置根据选定的进程拓扑加入本目录。

跨模块业务走 `../contracts/` 定义的公开网络 API，不导入其他模块内部代码、不访问其数据表。网络拓扑和数据库隔离须先写 ADR；模块内事务不代表跨模块事务。期末应真实演示网络调用写回。
