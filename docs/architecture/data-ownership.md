## 2. 来源、引用与派生数据

原稿明确的追溯语义：个人预约关联 M1 记录、整室占用关联 M2 申请、维修限制关联 M3 工单；新增、变更、解除都必须能解释来源。M3 一工单可有多条限制来源，恢复须逐条处理，不能仅按教室或工单粗粒度覆盖全部约束。（M1-R10/R21–R22；M2-R14/R19；S3 §3.14/4.2）

必须区分业务来源记录、具体占用/限制来源、一次请求/操作、通知及其处理记录；具体标识形态、唯一性范围、版本协议仍属 Q11/Q13。本文不固定字段名称或载荷。

AI 建议：本地历史可保存必要的资源展示快照，但需标记为当时视图，不用于替代 D 当前主数据或资源权威裁决；缓存/读模型失败时返回未知或错误，不伪造空闲。快照字段与保留期限待评审，不能新增不必要个人数据。

## 3. 事务边界与一致性责任

| 业务动作 | 本模块负责的事实 | 跨模块结果及不确定性 | 来源 |
| --- | --- | --- | --- |
| 个人创建 | M1 资格、日额度/预留、请求去重、预约记录 | 资源权威原子查座位/整室/用户重叠；资源成功但 M1 失败须核实恢复或只释放本来源；成功前双方事实确认 | M1-R08–R10/R15/R23；Q01/Q15 |
| 终审确认 | M2 锁定合法审批推进、保留 CONFIRMING/固定操作依据 | 资源权威全室与座位统一裁决；结果未知不换来源；跨开始先核实/安全清理再过期 | M2-R10–R11/R19–R21 |
| 普通撤销/提前结束 | M1/M2 本人归属、合法状态和业务时间，保留原计划/实际结束 | 资源权威按来源释放，返回未知不能假成功；未占用待审申请终止无须释放 | M1-R11/R13/R23；M2-R12–R14/R19 |
| 签到与超时 | M1 同一预约单一结果、违约去重及资格更新 | 需要核实有效停用/禁用；签到窗口不会因扫描延迟延长；停用延迟按可信时间更正 | M1-R12/R14–R15/R22–R24 |
| 紧急停用 | M3 保存授权安全决定；M1/M2 各取消自己的记录 | 资源权威先阻断，再通知；限制与业务取消不能假设同一事务，取消失败仍保持阻断；重试直到结果可核实 | M1-R19–R22；M2-R18–R21；S3 §3.13；Q08–Q10 |
| 完成/恢复 | M3 保存验收与安全恢复证据，M1/M2 保留取消历史 | 逐来源解除，资源权威综合其他来源；同步未知不提前显示恢复/完成，计划到期与未验收关系待决 | M1-R21；M2-R18；S3 §3.14；Q07/Q11 |

模块内事务不自动覆盖公开网络调用。即使最后共用物理数据库，也不得跨模块表写入以“解决原子性”。资源冲突的共同原子边界必须覆盖教室与全部座位，而 M1 个人资格/额度与资源结果的协调另有责任，二者不能相互替代。

AI 建议：后续实现通过持久操作依据、固定来源核实和幂等恢复满足原稿约束；具体采用何种数据库约束、事务隔离/锁或后台机制，在 Q01 等问题获结论后评审。不能把一把进程内锁视为多实例或重启安全证据。当前不选择实现。

## 4. 审查必须保持的业务不变量

| 不变量 | 来源与适用限制 |
| --- | --- |
| 重叠个人占用不能同座位双成功；同用户不能跨座位重叠；日额度含未知预留不得突破 | M1-R08–R10；额度持久恢复 Q15 |
| 整室与任一座位占用并发不能双成功；普通整室/计划施工不强制清场 | M1-R17/R19；M2-R15–R17；S3 §3.13 |
| 已确认紧急限制先阻断新增，业务取消稍后收敛；工单状态不代替限制确认状态 | M1-R20；M2-R18；S3 §1.6/3.13；失败处理 Q10 |
| 解除一个来源不清除其他来源，不重激活已系统取消的预约/申请 | M1-R20–R22；M2-R14/R18；S3 §3.14 |

| 资源可用性没有不带来源的“全部恢复空闲”写入口；颜色只是脱敏投影 | G §2/§4；M1-F03/R21；M2-R14 |

## 5. 隐私、评审与未完成项

公开时间轴只能显示必要原因，不能包含其他学生预约标识、用途全文、审批意见、故障全文或评价；身份及完整业务记录按归属/当前分配/管理范围授权。数据保留、删除、注销后的引用、人工违约更正与审计权限尚未确定，见 Q12/Q14，不能自行加处罚或扩大收集。（M1-R03/R23；M2-R04/R22；S3 §3.4；G §9）

本草案没有批准 D 扩责或建立 Schema。Q01 的所有权决策、Q06–Q07 的 M3 完整正文、Q08–Q11 的生效与异常语义、Q12 的主数据变更、Q15 的未知操作恢复是后续数据设计前置。团队确认后应把负责人、结论、日期、ADR/需求修订链接补入追踪；当前实现/PR/验收证据均未提供，等待人工评审。
